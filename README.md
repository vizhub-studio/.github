# VizHub open-source organization

The [VizHub](https://vizhub.com/) GitHub organization hosts reusable components, educational examples, historical systems, and experiments for interactive data visualization. Not every repository is part of the current hosted product.

## Selected public projects

- [VZCode](https://github.com/vizhub-studio/vzcode) — collaborative code editor.
- [VizHub Runtime](https://github.com/vizhub-studio/vizhub-runtime) — browser-based visualization runtime.
- [magic-sandbox](https://github.com/vizhub-studio/magic-sandbox) — multi-file HTML sandbox.
- [editcodewithai](https://github.com/vizhub-studio/editcodewithai) — code editing with LLMs.
- [Constructing Visualizations](https://github.com/vizhub-studio/constructing-visualizations) — course and textbook examples.

## Documentation scope

This repository is **public**. It includes only publicly discoverable repository information; detailed private-repository documentation planning belongs in a private workspace. Technical repository identifiers can be historical even when the user-facing product is now simply called **VizHub**.

The goal is a consistent, source-verified, and useful documentation experience without turning experimental work into unsupported product claims.
