**How to read this table:**
- **Last push** is GitHub's `pushed_at` date (UTC), **not** the date of the latest default-branch merge, deployment, or verified maintenance activity.
- **Wave** is a proposed documentation-review grouping, not a current maintenance or support guarantee.
- **Documentation focus** describes the work to verify in each PR; it is not a claim about the current feature set.
- **Status:** No Wave 1–3 documentation PRs are considered complete by this inventory alone. Track links and merge status during rollout.
